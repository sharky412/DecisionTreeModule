# Decision Tree Module

An interactive, story-driven module that teaches the basics of **decision trees**. A short introduction explains what decision trees are and where they show up in everyday life. You then guide an adventurer named Alex through a branching story, with each choice leading to a different path and ending.

## Features

- Step-by-step story introduction with next/previous navigation
- Interactive three-level decision tree (forest, mountains or river, and the choices that follow)
- A different outcome for every path through the tree
- Reset button to start the adventure again

## Tech stack

- React 19 (built with [Vite](https://vite.dev))
- Plain CSS

## Getting started

```bash
git clone https://github.com/sharky412/DecisionTreeModule.git
cd DecisionTreeModule
npm install
npm start
```

Then open http://localhost:5173/DecisionTreeModule/.

| Script            | Description                        |
| ----------------- | ---------------------------------- |
| `npm start`       | Start the Vite development server  |
| `npm run build`   | Create a production build          |
| `npm run preview` | Serve the production build locally |
| `npm run deploy`  | Build and publish to GitHub Pages  |
